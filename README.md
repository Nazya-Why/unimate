# Uni Mate

Студентський планер: предмети, лабораторні й практичні, дедлайни, нотатки, матеріали. Працює з телефона й ноутбука, можна додати на головний екран.

**Де дані.** Цей репозиторій містить лише код сайту, без жодних даних. Усе, що ви вносите, лежить у вашому **приватному** репозиторії `unimate-data` у файлі `data.json`, а завантажені файли — в теці `files/`. Сайт звертається до нього напряму через GitHub API з особистим токеном. Токен зберігається лише в браузері вашого пристрою.

**Вхід на новому пристрої.** Відкрийте сайт і створіть токен (fine-grained) з доступом лише до `unimate-data` і правом *Contents: Read and write*, потім вставте його. Робиться один раз на кожному пристрої.

**Синхронізація.** Зміни відправляються за ~1 с. Відкриті сторінки підтягують оновлення кожні 30 с і щоразу, коли ви повертаєтесь у вкладку. Якщо два пристрої змінили дані одночасно, зміни зливаються по окремих роботах, тож обидві відмітки зберігаються. Офлайн зміни лишаються на пристрої і відправляються, щойно з’явиться інтернет.
