Uni Mate

Вхід через GitHub. Дані лежать у твоєму приватному репозиторії, а ключ доступу зберігається лише на цьому пристрої. Робиться один раз на кожному телефоні чи ноутбуці.

  1. Відкрий створення токена на GitHub.
  2. Repository access → Only select repositories → обери unimate-data.
  3. Permissions → Contents → Read and write.
  4. Натисни Generate token, скопіюй його і встав нижче.

Токен відправляється лише на api.github.com.
